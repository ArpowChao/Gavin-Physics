# 電磁現象二與量子現象・學習筆記｜高中選修物理Ⅴ

依《選修物理（Ⅴ）》電流與電路、近代物理的重大發現、原子結構與原子核三章編排，並對照教育部 108 課綱第五學習階段學習內容（`PKc-Ⅴa-4`～`6`、`PKd-Ⅴa-1`～`8`、`PKe-Ⅴa-1`～`3`、`PMc-Ⅴa-1`～`2`）。

## 內容架構

- **課程導讀（16 節）**：涵蓋 1-1 至 3-6 每節目標、課本頁碼、公式與條件、例題與自我檢核。
- **互動模擬實驗室（10 組 SVG 模型）**：
  - CH1：歐姆元件與負載線工作點、串並聯電路與克希荷夫守恆
  - CH2：湯木生陰極射線管、密立坎油滴實驗、X 射線光譜、黑體輻射與紫外災難、光電效應
  - CH3：波耳氫原子能階躍遷、德布羅意物質波與駐波、原子核衰變與半衰期
- **逐概念練習（32 個概念、64 題）**：每節各概念配兩題單選與即時詳解，登入練習帳號同步記錄作答。
- **逐章練習卷（3 卷、每卷 12 題 100 分）**：含單選 40 分、多選 20 分、題組 24 分與手寫 16 分（附評分規準與 A4 空白／解答列印）。
